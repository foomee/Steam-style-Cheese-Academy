# ①課題名
Steam風チーズアカデミー

## ②課題内容（どんな作品か）
チーズアカデミーの素材を使って、[Steam](https://store.steampowered.com/)の作品ページ風LPを作りました。  

## ③アプリのデプロイURL
http://foomee.github.io/Steam-style-Cheese-Academy

## ④アプリのログイン用IDまたはPassword（ある場合）
今回はありません。

## ⑤工夫した点・こだわった点
- Steamの配色の雰囲気を持ちつつ、チーズをイメージした黄色の配色をしました。
- 上部の方だけ背景がグラデーションになっています。
- JSが必要な部分はAIに頼りました。
- SwiperというJSライブラリを使用して、画像をスライド表示できるようにしました。
- 2つあるヘッダーや、その内一方が画面上に固定されたり、下に一定量スクロールすると隠れ、上に少しスクロールすると再び表示される動作はこだわりました。
- 横幅が広い時は画像ギャラリーを左、チーズアカデミーの概要(ABOUT)を右に配置しています。HTMLでは画像ギャラリーを先に書いていますが、横幅が狭くなるとABOUTが上、画像ギャラリーが下になるようにしました。
- ニュースのリンクをクリックした際に何かしらのアクションが欲しかったので、疑似的に404ページを作りました。
- ユーザーレビューを追加してみました。名前や本文はAIに作ってもらいました。
- 個人的にCSSのgridに興味があったので、一部分だけ使ってみました。

## ⑥難しかった点・次回トライしたいこと（又は機能）
特別な機能が無いヘッダーを最初に作り始めましたが、ここが一番辛かったです。
素材が思い通りに表示されず、試行錯誤を繰り返していました。

その後、「Flexboxは直下の子要素に対して働く」ということを理解すると、加速度的に開発のスピードが上がった気がします。

Flexboxを使うために大きな箱を作って、その中に小さな箱を作って…ということをしていく内に「配置したい要素を、どの親要素の中にまとめるか」を考えるようになり、よりスムーズに作業を進められるようになりました。

## ⑦フリー項目（感想、シェアしたいこと等なんでも）
最初に仕様書と完成形の画像をAIに渡して、返ってきたものを少し手直しして、ひとまず課題を完成させて安心感を得てからSteam風チーズアカデミーに取り掛かりました。
この安心感が結構大きかったです。

やりたいことを実装するために何をすればいいかわからない時はAIに聞き、見慣れないCSSプロパティが出てくるとその都度調べていました。

作っている最中に「これはLPなのか？」と思いましたが、「(LPの常識を)こわそう、つくろう」の精神で、LPも作品ページも、商品やサービスに興味を持って貰う為のページで、役割は一緒だから問題無いだろうと自分を納得させました。
